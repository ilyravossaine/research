# Source Notes

## Purpose

This document describes how sources associated with Ilyra Vossaine's research were recorded and reviewed.

## Source Recording

References were collected in a central register to make them easier to locate and revisit. Each source was considered in relation to its relevance to the research.

## Review Practices

* Record the origin of each source where possible.
* Keep observations separate from information taken directly from a source.
* Revisit references when additional context becomes available.
* Preserve relevant supporting documentation for later review.

## Documentation Note

These notes describe the general approach to source management. The source register and individual research documents provide the associated records.
