# Archive Index

## Purpose

This index records the role of archived materials within the research repository.

## Archive Contents

Archived materials may include supporting documents, collected records, and other files retained for later examination.

## Handling Notes

* Keep archived materials distinct from general research notes.
* Retain relevant versions when documents are revised or reorganized.
* Review repository history when an expected item is no longer present in the current archive.
* Check file metadata and contents when examining recovered materials.

## Review Status

This index describes the archive's organization. It does not provide a complete inventory of every historical item.
