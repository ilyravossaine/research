# Archive Inventory

## Purpose

This inventory records the status of materials maintained in the research archive.

## Inventory Records

| Material             | Category               | Status            |
| -------------------- | ---------------------- | ----------------- |
| Research notes       | Working documentation  | Maintained        |
| Source references    | Reference material     | Maintained        |
| Supporting documents | Supplementary material | Review as needed  |
| Archived bundles     | Collected material     | Subject to review |

## Archive Handling

Materials may be grouped into compressed archives when several related files need to be retained together.

When an expected item is missing from the current archive, its earlier versions and repository history should be reviewed.

## Update Notes

This inventory should be updated when archived materials are added, replaced, or removed.
